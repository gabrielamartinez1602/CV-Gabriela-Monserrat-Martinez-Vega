# CV — Gabriela Monserrat Martinez Vega

Portafolio y currículum vitae en línea de **Gabriela Monserrat Martinez Vega**, diseñadora enfocada en **Branding, Motion Graphics e Ilustración**.

Este proyecto es una *landing page* de una sola página que aplica su sistema de diseño de marca personal: estética editorial, clásica y elegante con un gesto contemporáneo y artístico. Incluye paleta propia (*Winery Red* `#83232D`, *Sodalite Blue* `#282867`, negro y blanco), tipografías de identidad (**CoFo Raffine** y **Serenity**) y fotografías reales, logrando personalidad visual fuerte sin perder claridad profesional.
